## Open source — the AI infrastructure layer

> *Most people ask: "How do I make AI faster?"*
> *I ask: "What happens when AI breaks itself — and how do we prevent it?"*

These two tools come from that question.

### 🧹 Jhadoo — `pip install jhadoo`

**The disk cleanup tool built for the speed of modern AI development.**

ML engineers move fast. Conda environments, Docker images, stale branches, model checkpoints — they pile up silently until your machine crawls. Jhadoo sweeps it all up.

| Feature | What it does |
|---|---|
| 🌿 Smart Git & Docker | Finds stale branches and prunes Docker images older than 60 days |
| 🛡️ Safety first | Dry-run mode shows you exactly what will be deleted before anything happens |
| 📦 Archive mode | Not ready to delete? Move files to archive instead |
| ↩️ Instant undo | Deleted something by mistake? Restore it immediately |
| ⏰ Built-in scheduler | Set it to 2 AM. Wake up to a clean, fast machine |
| 📊 Dashboard | Track storage trends with progress bars and live notifications |

**Works on macOS, Windows, and Linux.**

- 📦 **4,000+ downloads**
- 🧹 Average savings: **18 GB per developer**
- 🏆 One ML engineer cleared **37 GB in seconds**

### 🛡️ Chowkidar — `pip install chowkidar`

**The Dependabot for your AI models. Because AI models expire — and nobody tells you until production crashes.**

In 2024 alone, OpenAI retired 7 model variants. If you use `gemini-1.5-flash`, it might die on June 6. Without Chowkidar, you find out when the app breaks on June 7. With Chowkidar, you get a heads-up in March and fix it in 10 minutes.

> *Dependabot tells you when your Python libraries are old.*
> *Chowkidar tells you when your AI models are about to kill your product.*

| Capability | Details |
|---|---|
| 🔍 Scans | `.env`, YAML, TOML, JSON, Python, JS, TS files for every model string |
| 🔄 Syncs | Official sunset schedules from OpenAI, Anthropic, Google, Mistral |
| 🚨 Warns | Desktop + terminal alerts at 90, 30, and 7 days before deprecation |
| 💰 Fixes | One-click replacements with cost savings and capability diff shown upfront |
| 🚦 CI/CD gate | `chowkidar gate` in GitHub Actions — fails the build if an expired model ships |
| 🤖 Zero-config IDE rules | Auto-generates rules for Cursor, Claude Code, VS Code, Windsurf |
| 🖥️ MCP server | Your IDE can query model status in real-time |
| 👁️ Background daemon | Watches your files 24/7 on macOS, Linux, Windows |
| 🔒 Local-first | Ollama + Gemma for smart logic. Your API keys never leave your machine |

**Featured on Google Cloud — Community (Medium).**

- 📦 **2,000+ downloads in weeks**
- ⚡ Turned a potential "2 AM production crash" into a "5-minute planned update"
- 💸 Switching models via Chowkidar can save up to **96% on token costs**
