## Open source — the AI infrastructure layer

### 🧹 [Jhadoo](https://github.com/bhav09/jhadoo) — `pip install jhadoo`
Disk hygiene for developers and ML teams. Cleans stale environments, caches, Docker artifacts, and repository clutter with safe recovery workflows.

**Works on macOS, Windows, and Linux.**  
📦 **6,000+ downloads** | Average **40 GB** saved per developer in lifetime savings.

### 👮🏻‍♂️ [Chowkidar](https://github.com/bhav09/chowkidar) — `pip install chowkidar`
Model lifecycle watchdog for GenAI applications. Detects upcoming model deprecations, scans codebases, and prevents expired AI models from reaching production. 

**Featured on Google Cloud — Community.**  
📦 **8,000+ downloads**

### 📟 [CodeMeter](https://github.com/bhav09/codemeter) 

An IDE extension that tracks AI coding costs, model usage, and agent spend across projects in real time.

📦 **1,500+ downloads**
